# Everything here is meant to be crawlable. The only thing worth keeping out is the
# private stats dashboard, which is key-gated anyway - this is belt and braces, and a
# reminder that a robots rule is NOT a security control.

# ---------------------------------------------------------------------------
# AI crawlers, split deliberately (added 18/08/2026).
#
# TRAINING crawlers are blocked below: they take the work into a model and give
# nothing back. SEARCH and RETRIEVAL crawlers are allowed in the group after that -
# they fetch a page to answer someone's question and cite the source, which is free
# promotion and the opposite of the problem.
#
# This does NOT affect Google or Bing rankings. Those use Googlebot and Bingbot,
# which are separate crawlers and are untouched here. Google-Extended governs Gemini
# TRAINING only; blocking it does not remove the site from Google Search.
#
# Note facebookexternalhit is deliberately NOT blocked - it renders link previews
# when someone shares a page, which is not training.
#
# robots.txt is VOLUNTARY. OpenAI, Anthropic, Google and Perplexity all state they
# honour it; nothing enforces it. Re-read this each quarter - these user agents get
# renamed and new ones appear.
